# Contributing Guidelines

Thank you for contributing to **Chargeback Sentinel**!

## Code of Conduct
We expect all contributors to adhere to our standards of professionalism, respect, and collaboration.

## Development Workflow
1. **Fork & Clone**: Fork the repository and clone it locally.
2. **Branching**: Create a feature branch (`git checkout -b feature/my-feature`).
3. **Environment Setup**:
   ```bash
   make install
   ```
4. **Testing**: Ensure all test suites pass before submitting:
   ```bash
   make test
   ```
5. **Pull Requests**: Submit a PR to `main` describing your changes and testing strategy.
